# Indian History Agent (Agentic RAG)

This project builds an AI system that answers ONLY Indian History questions
using a History of India book.

Key points:
- Uses RAG with LangChain
- Answers are sourced only from the book
- Every answer includes page numbers
- Off-topic questions are rejected
